# PineappleTAK core

This folder is the engine, sensors and web console from [PagerTAK](https://github.com/SECT0101/PagerTAK), the same code that runs on the WiFi Pineapple Pager. PineappleTAK runs it on the Mark VII through `../pineappletak.sh` and the Mark VII layer in `../mk7/`.

Every setting is in the web console. For what each feature does, see the [PagerTAK payload README](https://github.com/SECT0101/PagerTAK/blob/main/library/user/general/PagerTAK/README.md); the parts about the Pager's screen, buttons and menus do not apply to the Mark VII.
